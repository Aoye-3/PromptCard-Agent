# Canvas Agent 被修改对象选择器设计

## 目标

把“已发送给 Agent 的文本节点”和“本轮允许修改的唯一节点”拆成两个明确概念。普通加入的节点先作为参考，被修改对象默认空置；用户可以从已挂载节点中显式选择目标。画布右键“补全”保留为快捷入口，直接挂载并选中该节点作为目标。

## 交互

- 标签区顶部提供独立的“被修改对象”选择器。
- 没有目标时显示空态按钮，点击后展开已挂载节点列表；没有挂载节点时显示不可选空态。
- 选择节点后，该节点成为唯一目标；旧目标自动恢复为参考。
- 清空目标只取消其目标身份，不从标签池删除，节点仍可作为参考和 `@` 引用。
- 参考标签继续完整展示并支持删除；删除当前目标时同时清空目标。
- `@` 菜单继续只展示已挂载节点，并显示目标/参考身份。
- 画布右键“发送到 Agent”只添加参考；“补全”直接设为目标并切换到补全模式。

## 权限与数据

继续使用现有 `CanvasAgentAttachment` 角色模型。未选择目标时请求发送 `targetNodeId: null`，Gateway 仅允许讨论、不得产生画布写入提案。选择目标后仍由 Gateway 校验目标唯一性、参考只读与当前项目归属。

## 验收

- 仅添加参考节点时，被修改对象保持空置。
- 可从已挂载节点列表选择唯一目标，并可清空目标。
- 切换目标时旧目标回到参考集合，节点不会丢失或重复。
- 右键“补全”仍直接设定目标；“发送到 Agent”不设定目标。
- 发送请求在空目标时携带 `targetNodeId: null`。
